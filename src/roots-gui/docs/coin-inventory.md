# Observed coin inventory

UTXOs reads the existing verified wallet refresh ledger. It adds no RPC method,
index allocation, import, funding, signing, broadcast or daemon-management route.
Exact backend/session, genesis, actual daemon-wallet name, document/query revision,
lock epoch, generation and sequence bind observations. Offline and failed refreshes
retain dated values and exact selections, with current eligibility Unknown.

The bounded owner-thread inventory retains at most8192 distinct outpoints. A
retention/adoption error leaves its prior rows and selections intact. Current
`listunspent(minconf=0, include_unsafe=true)` evidence includes the existing
`include_immature_coinbase` query option. Public address, label, locking script,
amount, safety and solvability are observations. In this pinned Roots source,
`spendable` is deprecated and always true; `solvable` ignores missing keys.
Neither field proves custody, a signing capability or final local spendability.
Parent dates/output associations need exact txid/vout and consistent public
locking-script/value evidence. Missing parent/prevout/current-chain data remain
Unknown. A disappeared row retains its last observed value/date and explains
that spent, daemon-locked or otherwise missing inventory cannot be distinguished
merely by absence. It never substitutes another input or loses the exact selected
identity. Incomplete inventory totals/chart are Unknown, not fabricated zero.

The summary distinguishes observed count/total from eligible amount. The
[coin-control service](coin-controls.md) supplies acknowledged local freeze and
GUI reservation policy only under current complete identity/observation proof.
Missing policy, lock or output evidence stays Unknown. This is not custody or
funding approval. Immature/unsafe/unsolvable observations explain exclusions.
Presentation selection remains separate from explicitly pinned draft inputs.

The Date/Output/Address/Label/Value table supports stable outpoint multi-selection,
value/date sorting and retained unavailable rows. Full identifiers, dated reasons
and exact amounts remain in tooltips/semantic text. The linked chart sorts exact
values descending with an outpoint tie-break, shows nine individual outputs and
aggregates every remaining present output into Other using checked int64 addition.
Retired rows are excluded from that inventory chart/total. Pointer bars and
Previous/Toggle group/Next text/keyboard controls update the same selection set.
Only chart geometry/share uses approximate floating arithmetic; displayed/exported
financial values remain exact. A partially selected Other group is distinguished.
The footer reports selected/observed counts, last-observed selected value and the
separate eligible amount. Selection changes issue no transaction command.

Output labels override dated daemon labels locally. Enter, native focus loss and
semantic SetValue use acknowledged scoped metadata CAS. A failure retains both
the exact draft and previously saved label, reports its reason and requires a
new edit/Enter or deliberate reload/retry; redraw never retries a failed save.
Selection/clipping/editor disappearance retires activation once. Wallet/query,
privacy, lock and metadata-revision changes cannot redirect an old activation.
Metadata writes use the existing encrypted-store ownership and error contracts.

CSV exports the exact observed values, dates/outpoints, labels, provenance,
current/dated reason and explicitly named heuristics. Cells quote/escape newlines
and quotes, and neutralize spreadsheet formulas without altering numeric amounts.
Exports require a new absolute local filename: exclusive/no-follow creation never
replaces an existing file. Write/durability failures remain visible; a partial
new file may remain. A chooser result after view/revision/observation/privacy
change is retired. Hiding amounts disables export/value-sort, removes chart
geometry and conceals financial totals, labels and counts across visible and
semantic channels. Public identifiers remain available for inspection.

Address reuse is an optional daemon observation/heuristic, not a privacy promise;
absence of its flag proves no negative. The fixed small-value marker (<546 sats)
is explicitly a heuristic and **not** script/fee-dependent relay dust policy.
Neither heuristic changes eligibility or excludes/selects a coin automatically.

Public recovery codec4 additionally stores presentation selection/focus/sort and
independent output-label draft buffers. Versions1/2/3 remain readable. Metadata
acknowledgements, observations, policy authority and executable actions are never
restored. Clear/close retain these drafts through the existing opt-in recovery
contract; privacy lock erases sensitive views/caches/accessibility state.

Focused coverage includes exact sums/top-nine/Other, missing/contradictory prevouts,
stable selection after sort/refresh/disappearance, labels/CAS/focus loss, privacy,
CSV and recovery. One owned Roots/Linux native960x640/150% journey exercises real
selection/sort, immature availability, read-only disconnect/stale state and hidden
amounts. Controller setup uses disposable regtest funds and an explicit test-only
public-descriptor startup opt-in for before/after index comparison. The GUI never

other platforms, physical hardware/assistive devices, real chooser delivery and
parent full-suite/performance qualification retain their separate pending gates.
