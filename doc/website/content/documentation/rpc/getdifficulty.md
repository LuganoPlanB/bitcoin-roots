# getdifficulty

Returns the proof-of-work difficulty as a multiple of the minimum difficulty.

```sh
bitcoin-cli getdifficulty
```

## Arguments

No arguments.

## Return value

`numeric`. the proof-of-work difficulty as a multiple of the minimum difficulty.
